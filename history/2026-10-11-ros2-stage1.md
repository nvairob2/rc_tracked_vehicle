# 2026-10-11 — Этап 1: геймпад через ROS2 (Wi‑Fi / micro-ROS)

## Решение

`opi5` пока не на раме — физического UART/USB нет. Команды моторов возвращаются на ESP32 по ROS2 (UDP), затем уходят в STM32 по существующему `"move,turn\n"`.

Переключатель **Select** на геймпаде: **Direct** (микшер на ESP32, как сейчас) ↔ **ROS2** (сырой `/joy` → `tank_teleop` на opi5 → `/cmd_vel` → ESP32 → STM32).

**Start** — защёлка стопа, не путать с Select.

## Сеть

- ESP32 AP: `HeavyTank_10KG` / `192.168.4.1`
- opi5: статический `192.168.4.2`, `micro-ros-agent` UDP `:8888`

## Контракт топиков

Стандартные сообщения (`Joy`, `Twist`, `String`) — без кастомных `.msg` (Arduino + micro-ROS).

Микшер гейпада в ROS2-режиме живёт в Python (`tank_teleop`), на ESP32 в этом режиме только опрос PS2.
