# PS2-геймпад 2.4 GHz — подключение и логика управления

> Приёмник: беспроводной dongle PS2-совместимый (9-pin), например [AliExpress 1005012254539073](https://aliexpress.ru/item/1005012254539073.html).  
> Прошивка с геймпадом: `sources/ESP32/vehicle_controller_ps2/vehicle_controller_ps2.ino` (Wi‑Fi + веб-пульт **и** PS2).  
> Без геймпада: `sources/ESP32/vehicle_controller/vehicle_controller.ino` (только Wi‑Fi).

---

## 1. Архитектура

```text
  PS2 геймпад ── 2.4 GHz ──► приёмник (9 pin)
                                  │
                     DATA / CMD / ATT / CLK + 3.3V / GND
                                  │
                           ESP32-S3  ── UART 115200 ──►  STM32F411  ──►  BTS7960 ×2
                           Wi‑Fi AP + WebServer              move,turn\n
                           http://192.168.4.1/
```

| Узел | Роль |
| :--- | :--- |
| **ESP32-S3** | Wi‑Fi, веб-пульт, опрос PS2, расчёт `move,turn`, UART → STM32 |
| **STM32** | ШИМ, энкодеры, контур скорости — **без изменений** |
| **PS2-приёмник** | Только к ESP32, не к STM32 |

## 2. Разъём приёмника 9 pin

Вид на **контакты разъёма dongle** (отверстия под штырь), pin **1 слева**:

| Pin | Сигнал | ESP32-S3 Expansion | Примечание |
| :---: | :--- | :--- | :--- |
| **1** | **DATA** | **GPIO4** | вход (MISO) |
| **2** | **CMD** | **GPIO5** | выход (MOSI) |
| **3** | **9V** | **NC** | вибромотор; на 2.4 GHz dongle обычно не нужен |
| **4** | **GND** | **GND** | общая земля с STM32 |
| **5** | **VCC** | **3.3 V** | логика **3.3 V**, не 5 V |
| **6** | **ATT** (CS) | **GPIO6** | выбор устройства |
| **7** | **CLK** | **GPIO7** | тактирование |
| **8** | NC | NC | — |
| **9** | **ACK** | **NC** | библиотека PS2X работает без ACK |

> Цвета проводов у клонов разные — **прозвонить pin 1…9** на корпусе перед пайкой.

### Схема (жгут)

```text
  PS2 Receiver 9-pin              ESP32-S3 Expansion
  ─────────────────              ────────────────────
  1 DATA  ─────────────────────── GPIO4
  2 CMD   ─────────────────────── GPIO5
  3 9V    ─── (не подключать)
  4 GND   ─────────────────────── GND ──── GND STM32 (UART)
  5 VCC   ─────────────────────── 3.3V
  6 ATT   ─────────────────────── GPIO6
  7 CLK   ─────────────────────── GPIO7
  8,9     ─── NC

  UART (без изменений):
  GPIO43 TX ───────────────────── STM32 PB7 (RX)
  GPIO44 RX ───────────────────── STM32 PB6 (TX)
```

**Level shifter не нужен** (3.3 V ↔ 3.3 V). Ток dongle ~30–80 mA от **3.3 V** ESP32.

### Занятые GPIO ESP32

| GPIO | Назначение |
| :--- | :--- |
| 43 | UART TX → STM32 |
| 44 | UART RX ← STM32 |
| 4 | PS2 DATA |
| 5 | PS2 CMD |
| 6 | PS2 ATT |
| 7 | PS2 CLK |

Не использовать **GPIO0, GPIO45, GPIO46** (strapping). **GPIO19/20** — USB, не трогать при питании через USB.

## 3. Логика управления (прошивка ESP32)

Протокол к STM32: строка **`move,turn\n`**, диапазон **−255…255**.

На STM32: `cmd1 = move + turn` (левый борт), `cmd2 = move − turn` (правый борт).

### 3.1. Базовая скорость — D-pad и плечи

| Кнопка | Действие |
| :--- | :--- |
| **↑** (разово) | `baseSpeed += 10` (max **+255**) |
| **↓** (разово) | `baseSpeed -= 10` (min **−255**, задний ход) |
| **L1 / R1** (кнопки 1, пока нажаты) | тот же шаг **каждые 80 мс** по знаку хода: вперёд → +, назад → ещё быстрее назад |
| **← / →** (пока нажаты) | разворот на месте (`move=0`, `turn=±pivot`) |
| **L2 / R2** (кнопки 2, фронт нажатия) | **защёлка стоп**: `baseSpeed = 0` постоянно, не только на время удержания |

`baseSpeed` по умолчанию **0**. После L2/R2 разгон снова крестиком или L1/R1.

`pivot = max(|baseSpeed|, 80)`.

### 3.2. Джойстики — скорость каждого борта

| Ось | Борт |
| :--- | :--- |
| **LY** (левый стик, вертикаль) | левый |
| **RY** (правый стик, вертикаль) | правый |

В PS2X: **0** = стик вперёд, **255** = назад, **~128** = центр.

Стик **не реверсирует** борт: против текущего `baseSpeed` только торможение до 0.

| `baseSpeed` | Стик вперёд | Центр | Стик назад |
| :--- | :--- | :--- | :--- |
| **> 0** | до **+255** | `baseSpeed` | до **0** |
| **< 0** | до **0** | `baseSpeed` | до **−255** |
| **= 0** | 0 | 0 | 0 |

Кратковременно отпустить газ / остановиться — потянуть оба стика против хода; после отпускания снова `baseSpeed`.

### 3.3. L2 / R2 — защёлка стоп

Короткое нажатие **L2** или **R2** обнуляет `baseSpeed`. Удерживать не нужно.

### 3.4. Перевод в move / turn

```text
leftCmd, rightCmd  →  move = (left + right) / 2
                      turn = (left - right) / 2
```

### 3.5. Wi‑Fi и геймпад параллельно

| Источник | Поведение |
| :--- | :--- |
| **Веб-пульт** | `http://192.168.4.1/` → кнопки шлют `move,turn` по HTTP |
| **Геймпад** | опрос каждые **20 ms**, UART при изменении команд или раз в 20 ms |
| **Приоритет** | оба канала активны; последняя отправленная команда побеждает на STM32 |

Если dongle не подключён или не инициализировался — **Wi‑Fi работает как раньше**.

## 4. Сборка прошивки ESP32

### Библиотека

В Arduino Library Manager **PS2X_lib нет**. Это не официальный пакет.

В скетч уже положен форк под ESP32 ([MyArduinoLib/Arduino-PS2X-ESP32](https://github.com/MyArduinoLib/Arduino-PS2X-ESP32)):

- `sources/ESP32/vehicle_controller_ps2/PS2X_lib.h`
- `sources/ESP32/vehicle_controller_ps2/PS2X_lib.cpp`

Arduino IDE компилирует их вместе со скетчем, ничего ставить не нужно. Открой именно папку `vehicle_controller_ps2`, не копируй один `.ino`.

Оригинал AVR: [madsci1016/Arduino-PS2X](https://github.com/madsci1016/Arduino-PS2X) — на ESP32-S3 не соберётся.

### Плата

**ESP32S3 Dev Module** (или ваша Expansion Board), как для Wi‑Fi-пульта.

### Отключить геймпад без удаления кода

В `vehicle_controller_ps2.ino`:

```cpp
#define ENABLE_PS2_GAMEPAD 0
```

Либо прошить исходный `vehicle_controller.ino` (только Wi‑Fi).

### Проверка Serial (ESP32-S3)

Строки `Serial` **не** появляются в окне компиляции Arduino IDE. Нужен **Tools → Serial Monitor**, порт USB платы ESP32, 115200.

После Upload порт часто пропадает — закрой монитор, выбери порт заново, открой монитор снова.

В Tools обязательно:

| Пункт | Значение |
| :--- | :--- |
| USB CDC On Boot | **Enabled** |
| USB Mode | Hardware CDC and JTAG |
| USB DFU On Boot | Disabled |

Если CDC выключен, `Serial` идёт на GPIO43/44 (UART к STM32), а USB-монитор пустой.

В мониторе раз в секунду должна быть строка `HB t=...`. Если её нет — смотришь не тот порт или CDC выключен.

1. Serial Monitor **115200** — сообщение об инициализации PS2 (OK или код ошибки).
2. Wi‑Fi: SSID `HeavyTank_10KG`, браузер **http://192.168.4.1/**.
3. Геймпад включить **до** прошивки/сброса ESP32 (или подождать повтор init каждые 2 с).
4. Serial Monitor: порт **USB ESP32**, 115200. Должны идти строки `PS2:` / `GP` каждые 0.5 с.
5. Если `init=1` — нет ответа dongle: питание 3.3V, общий GND, пины 4/5/6/7, геймпад в режиме analog (красный LED).
6. Если `ok=1`, но `LY=128 RY=128` и кнопки 0 — протокол жив, но кнопки не читаются (часто analog off).
7. Если вообще пусто — открыт не тот Serial (STM32/ST-Link), либо USB CDC: Tools → USB CDC On Boot = Enabled.
