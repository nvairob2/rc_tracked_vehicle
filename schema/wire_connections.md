# Каноническая карта портов BlackPill (боевая прошивка)

Актуально для `sources/STM32/motor_controller/motor_controller.ino`.  
UART к ESP32 и энкодеры не конфликтуют.

Таймеры / входы:
* **TIM3** — ШИМ борта 1 (`PA6`/`PA7` через `analogWrite`)
* **TIM2** — ШИМ борта 2 (`PA15`/`PB3` через `analogWrite`)
* **EXTI** — энкодеры борта 1 (`PA0`/`PA1`) и борта 2 (`PA8`/`PA9`)
* **USART1** — связь с ESP32 на `PB6`/`PB7`

---

## БОРТ 1 (Левый)

| Сигнал | Назначение | Пин | Режим |
| :--- | :--- | :--- | :--- |
| **RPWM_1** | ШИМ вперёд | `PA7` | PWM |
| **LPWM_1** | ШИМ назад | `PA6` | PWM |
| **EN_1** | Включение драйвера 1 | `PA2` | GPIO |
| **Энкодер 1, A** | Провод 3 шлейфа | `PA0` | EXTI (CHANGE) |
| **Энкодер 1, B** | Провод 4 шлейфа | `PA1` | GPIO input |

## БОРТ 2 (Правый)

| Сигнал | Назначение | Пин | Режим |
| :--- | :--- | :--- | :--- |
| **RPWM_2** | ШИМ вперёд | `PA15` | PWM |
| **LPWM_2** | ШИМ назад | `PB3` | PWM |
| **EN_2** | Включение драйвера 2 | `PA3` | GPIO |
| **Энкодер 2, A** | Провод 3 шлейфа | `PA8` | EXTI (CHANGE) |
| **Энкодер 2, B** | Провод 4 шлейфа | `PA9` | GPIO input |

## UART (ESP32 ↔ STM32)

| Сигнал | Пин STM32 |
| :--- | :--- |
| TX → ESP32 RX | `PB6` |
| RX ← ESP32 TX | `PB7` |

## Питание логики энкодеров

* **VCC** (провод 2 шлейфа) → `5V` BlackPill
* **GND** (провод 5 шлейфа) → `GND` BlackPill

| :--- | :--- |
| IS борт 1 | `PA4` (ADC) |
| IS борт 2 | `PA5` (ADC) |
