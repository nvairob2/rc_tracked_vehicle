# Макетка 60×80 мм — дизайн коммутации (п.6)

> Размер: **60×80 мм** (не см), сетка **22×27** отверстий, шаг **2.54 мм**.  
> Цель: перенести сигнальную обвязку со стендового breadboard на паяную плату, не трогая силовые цепи драйверов.

## 1. Что на этой плате, а что нет

| На макетке 60×80 | Вне платы (как сейчас) |
| :--- | :--- |
| STM32 Black Pill (F411) | ESP32-S3 на **своей Expansion Board** с клеммами |
| Клеммы/штыри логики к 2× BTS7960 | Сами модули BTS7960 (силовые B+/B−, M+/M−) |
| Клеммы энкодеров 2× мотора | Силовая 3S LiPo |
| Ввод 5V/GND от UBEC | UBEC (крепление рядом, только провода 5V/GND на плату) |
| UART TX/RX/GND → клеммы ESP expansion | Wi‑Fi / веб-пульт |
| Опционально: защита IS (стабилитрон 3.3 В) | |

**Принцип:** по макетке идут только логика и 5V. Токи моторов (амперы) — только по штатным силовым проводам драйверов, не через отверстия 2.54.

---

## 2. Система координат отверстий

- Ось **X**: столбцы `1…22` (короткая сторона ~60 мм)  
- Ось **Y**: ряды `1…27` (длинная сторона ~80 мм)  
- Отверстие `(1,1)` — левый нижний угол при виде **со стороны пайки компонентов сверху** (стандарт «шелкография сверху»).

Полезная площадь без крайних рядов крепежа: примерно `X=2…21`, `Y=2…26`.

---

## 3. Зоны платы (вид сверху)

```text
         X →  1                         22
       Y  ┌──────────────────────────────┐
      27  │ ● крепёж              крепёж ●│
          │                              │
      25  │  J_PWR(5V)    J_UART→ESP     │  ← верх: питание + связь с ESP
          │  [2pin]       [3pin]         │
          │                              │
      20  │     ┌─────────────────┐      │
          │     │  BLACK PILL     │      │  USB / BOOT к правому краю
      12  │     │  STM32F411      │      │  (удобно прошивать на машине)
          │     └─────────────────┘      │
          │                              │
       8  │  J_DRV1          J_DRV2      │  ← логика драйверов
          │  (7 pin)         (7 pin)     │
          │                              │
       4  │  J_ENC1          J_ENC2      │  ← энкодеры моторов
          │  (4 pin)         (4 pin)     │
       1  │ ● крепёж              крепёж ●│
          └──────────────────────────────┘
```

### Размещение Black Pill

- Ориентация: **длинной стороной вдоль Y** (вверх–вниз), USB-разъём к **правому** краю платы (`X` большим).  
- Примерный контур корпуса: ~21×53 мм → занимает примерно `X=7…14`, `Y=10…22` (уточнить по фактической WeAct V2).  
- Под плату — **женские штыревые колодки 2.54** (не паять MCU намертво): можно снять для отладки.  
- Пины, которые используем, вывести перемычками на соседние дорожки к клеммам.

---

## 4. Разъёмы (клеммные колодки 2.54 или DFRobot/KF301)

Именовать так же, как в прошивке — меньше ошибок при переносе.

### J_PWR — питание логики от UBEC (2 пина)

| Пин разъёма | Сигнал | Куда на STM32 |
| :---: | :--- | :--- |
| 1 | **5V** | 5V Black Pill |
| 2 | **GND** | GND Black Pill |

> ESP32 питается **со своей** Expansion Board / своим вводом 5V. На UART-жгуте между платами достаточно **GND + TX + RX** (общий 5V между UBEC и ESP — только если земли и питания уже сведены осознанно на корпусе).

### J_UART — к Expansion Board ESP32 (3 пина)

| Пин | Сигнал | STM32 | ESP Expansion (клемма) |
| :---: | :--- | :--- | :--- |
| 1 | GND | GND | GND |
| 2 | STM32 TX | **PB6** | RX (GPIO44) |
| 3 | STM32 RX | **PB7** | TX (GPIO43) |

Жгут 10–20 см, экранировать не обязательно; витой GND+сигналы желателен.

### J_DRV1 / J_DRV2 — логика BTS7960 (по 7 пинов, одинаковая распиновка)

| Пин | Сигнал | STM32 борт1 | STM32 борт2 |
| :---: | :--- | :--- | :--- |
| 1 | GND | GND | GND |
| 2 | VCC 5V (логика драйвера) | 5V | 5V |
| 3 | R_EN+L_EN | **PA2** | **PA3** |
| 4 | RPWM | **PA7** | **PA15** |
| 5 | LPWM | **PA6** | **PB3** |
| 6 | IS (R_IS∥L_IS) | **PA4** | **PA5** |
| 7 | (резерв / экран) | — | — |

На каждом модуле BTS7960: **R_IS и L_IS замкнуты перемычкой** до одного провода в пин 6.

### J_ENC1 / J_ENC2 — энкодер мотора (4 пина)

| Пин | Сигнал шлейфа | STM32 борт1 | STM32 борт2 |
| :---: | :--- | :--- | :--- |
| 1 | VCC (провод 2) | 5V | 5V |
| 2 | A (провод 3) | **PA0** | **PA8** |
| 3 | B (провод 4) | **PA1** | **PA9** |
| 4 | GND (провод 5) | GND | GND |

M+ / M− (провода 1 и 6) на макетку **не заводить** — только на силовые клеммы драйвера.

## 5. Шины на плате (пайка)

Рекомендуемые сплошные дорожки (голый провод Ø0.5–0.8 или перемычки):

1. **GND** — по длинному краю `X=2`, от `Y=2` до `Y=26`, отводы ко всем разъёмам и к GND Black Pill.  
2. **5V** — зеркально по `X=21` или второй ряд рядом с GND, к J_PWR, VCC драйверов, VCC энкодеров, 5V MCU.  
3. Сигналы — короткие перемычки MCU → ближайшая клемма (не пересекать силовые жгуты моторов).

### Защита IS (рекомендуется в зоне J_DRV)

Между пином IS и GND, у разъёма:

- стабилитрон **3.3 В** (катод на IS, анод на GND),  
- опционально последовательный резистор 1 кΩ между модулем и входом АЦП.

Места: рядом с `J_DRV1` пин 6 и `J_DRV2` пин 6 (2–3 отверстия).

---

## 6. Крепёж и механика на машине

- 4 отверстия Ø3 мм в углах (рядом с `(1,1)`, `(22,1)`, `(1,27)`, `(22,27)` — сверлить с запасом, не по сигнальным дорожкам).  
- Стойки М3, плата **выше** металлических частей шасси.  
- ESP Expansion Board — рядом отдельным креплением; жгут UART только сигнальный.  
- BTS7960 — ближе к моторам / батарее; жгуты J_DRV короткие.

---

## 7. Порядок сборки (чеклист)

1. Установить угловые стойки / разметить крепёж.  
2. Паять шины GND и 5V.  
3. Поставить колодки под Black Pill, прошить/проверить вне машины.  
4. Припаять клеммные блоки J_* .  
5. Развести сигналы по таблице §4, прозвонить мультиметром **до** подключения драйверов.  
6. Стабилитроны на IS.  
7. Подключить UBEC → J_PWR, проверить 5V.  
8. UART → ESP Expansion (GND общим!).  
9. J_DRV / J_ENC → драйверы и энкодеры.  
10. Прогон: STOP `I≈0`, FORWARD как на стенде.

---

## 8. Что сознательно не влезает / не кладём сюда

- Два BTS7960 целиком (габарит + нагрев + силовые токи).  
- ESP32 + Expansion Board (уже есть клеммы — дублировать незачем).  
- Силовая разводка батареи.

При нехватке места на 22×27: первыми жертвами сделать «резерв» пин 7 на J_DRV и перенести защиту IS на навесной монтаж у драйвера.
